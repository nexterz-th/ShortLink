# Link. — ระบบย่อลิงก์ (PHP + MySQL)

ระบบย่อลิงก์พร้อมหลังบ้านครบชุด ใช้ PHP ล้วน + MySQL ไม่ต้องใช้ Composer หรือ Node
ออกแบบให้อัปโหลดขึ้น Plesk ได้ทันที ใช้ฟอนต์ **IBM Plex Sans Thai** รองรับโหมดสว่าง/มืด

## ความสามารถ

**หน้าเว็บ**
- ย่อลิงก์จากหน้าแรก พร้อมตัวเลือกขั้นสูง (โค้ดเอง / ชื่อ / รหัสผ่าน / วันหมดอายุ)
- หน้าสถิติสาธารณะของแต่ละลิงก์ที่ `/p/{code}`
- หน้าใส่รหัสผ่านก่อนเข้าลิงก์ที่ถูกล็อก

**หลังบ้าน** (`/admin/`)
- ภาพรวม: ลิงก์ทั้งหมด คลิกสะสม คลิกวันนี้ กราฟ 14 วัน อุปกรณ์ เบราว์เซอร์ ลิงก์ยอดนิยม
- จัดการลิงก์: ค้นหา กรองสถานะ เรียงลำดับ แบ่งหน้า เลือกหลายรายการเพื่อเปิด/ปิด/ลบ ส่งออก CSV
- สร้าง/แก้ไขลิงก์: เปลี่ยนปลายทางได้โดยลิงก์ย่อไม่เปลี่ยน, รหัสผ่าน, วันหมดอายุ, จำกัดจำนวนคลิก
- สถิติรายลิงก์: กราฟ 7/14/30/90 วัน, อุปกรณ์, เบราว์เซอร์, OS, แหล่งที่มา, การคลิกล่าสุด
- ประวัติการคลิกทั้งระบบ
- ผู้ใช้งาน: เพิ่ม/ลบ, สิทธิ์ผู้ดูแลระบบและผู้แก้ไข, เปิด-ปิดบัญชี, ตั้งรหัสผ่านใหม่
- ตั้งค่าระบบ: ชื่อเว็บ, เปิด/ปิดให้คนทั่วไปย่อลิงก์, ความยาวโค้ดสุ่ม, จำกัดจำนวนต่อ IP, โดเมนต้องห้าม, ลบประวัติเก่า

**ระบบกัน bot บนฟอร์มย่อลิงก์หน้าแรก** (3 ชั้น ตั้งค่าได้จากหลังบ้าน)
1. **CAPTCHA รูปภาพในตัว** — วาดด้วย GD ไม่พึ่งบริการภายนอก ไม่ต้องใช้ API key
   ตัวอักษรเอียงสุ่มมุม มีเส้นและจุดรบกวน ตัดตัวอักษรที่สับสนง่ายออก (0/O, 1/I) กดสุ่มใหม่ได้
   โจทย์ใช้ได้ครั้งเดียวและหมดอายุใน 10 นาที · หากเซิร์ฟเวอร์ไม่มี GD จะถอยไปใช้โจทย์บวกเลขอัตโนมัติ
2. **Honeypot** — ช่องที่ซ่อนจากผู้ใช้จริง แต่ bot มักกรอก ถ้ามีค่าจะถูกปฏิเสธทันที
3. **ดักเวลา** — ปฏิเสธฟอร์มที่ส่งภายใน 2 วินาทีหลังโหลดหน้า

ตั้งค่าได้ที่ **ตั้งค่าระบบ → การยืนยันตัวตนกัน bot**: เฉพาะผู้ที่ไม่ได้เข้าสู่ระบบ (ค่าเริ่มต้น) /
บังคับทุกคน / ปิดใช้งาน — ใช้ร่วมกับการจำกัดจำนวนลิงก์ต่อ IP ต่อชั่วโมง

**ความปลอดภัย**
- รหัสผ่านเข้ารหัสด้วย `password_hash()`
- ทุกฟอร์มมีโทเคน CSRF
- ทุก query ใช้ prepared statement
- จำกัดจำนวนครั้งการเข้าสู่ระบบผิดและการสร้างลิงก์ต่อ IP
- คุกกี้เซสชันแบบ HttpOnly + SameSite

## ความต้องการของระบบ

- PHP 8.0 ขึ้นไป (เปิดส่วนขยาย `pdo_mysql` และ `gd` สำหรับ CAPTCHA รูปภาพ — ไม่มีก็ใช้งานได้แต่จะเป็นโจทย์เลข)
- MySQL 5.7 / MariaDB 10.3 ขึ้นไป
- Apache พร้อม `mod_rewrite` (ค่าเริ่มต้นของ Plesk เปิดอยู่แล้ว)

## วิธีติดตั้งบน Plesk

1. **สร้างฐานข้อมูล** — Plesk → Databases → Add Database จดชื่อฐานข้อมูล ผู้ใช้ และรหัสผ่านไว้
2. **อัปโหลดไฟล์** — อัปโหลดทั้งโฟลเดอร์นี้ขึ้นไปที่โดเมน (เช่น `/httpdocs/`)
3. **ตั้ง Document Root** — Plesk → Hosting Settings → Document root ให้ชี้ไปที่โฟลเดอร์ `public`
   (เช่น `httpdocs/public`) — วิธีนี้ปลอดภัยที่สุดเพราะโค้ดใน `app/` จะเข้าถึงจากเว็บไม่ได้เลย
   *หากเปลี่ยน document root ไม่ได้* ให้อัปโหลดทุกอย่างไว้ที่ราก แล้วไฟล์ `.htaccess` ที่รากจะ
   ส่งทราฟฟิกเข้า `public/` และปิดกั้น `app/` ให้เอง
4. **ตั้งค่า PHP** — Plesk → PHP Settings เลือก PHP 8.0 ขึ้นไป
5. **เปิดเว็บ** — เข้าเว็บไซต์ ระบบจะพาไปหน้า `/install.php` โดยอัตโนมัติ
   กรอกข้อมูลฐานข้อมูล ชื่อเว็บ URL หลัก และบัญชีผู้ดูแลระบบ แล้วกด "เริ่มติดตั้ง"
6. **ลบไฟล์ติดตั้ง** — เมื่อติดตั้งเสร็จ ให้ลบ `public/install.php` ออกเพื่อความปลอดภัย
7. **เปิด SSL** — ติดตั้ง Let's Encrypt จาก Plesk แล้วยกเลิกคอมเมนต์บล็อกบังคับ HTTPS
   ใน `public/.htaccess`

### ดึงจาก GitHub ผ่าน Plesk Git (แนะนำสำหรับการอัปเดตภายหลัง)

1. Plesk → โดเมน → **Git** → Add Repository → เลือก Remote Git repository
2. URL: `https://github.com/nexterz-th/ShortLink.git` · Branch: `main`
3. Deployment path ตั้งเป็นโฟลเดอร์ของโดเมน แล้วตั้ง document root ไปที่ `public` ตามข้อ 3 ด้านบน
4. เปิดเว็บครั้งแรกเพื่อรัน `/install.php` แล้วลบไฟล์นั้นทิ้ง

ไฟล์ `app/config.local.php` ถูกใส่ไว้ใน `.gitignore` แล้ว การกด Pull ครั้งต่อ ๆ ไป
จึงไม่ทับคอนฟิกฐานข้อมูลบนเซิร์ฟเวอร์ และไม่ทำให้รหัสผ่านหลุดขึ้น repo สาธารณะ

ตัวติดตั้งจะสร้างไฟล์ `app/config.local.php` ให้เอง (ต้องให้โฟลเดอร์ `app/` เขียนไฟล์ได้ชั่วคราว)
หากต้องการติดตั้งใหม่ ให้ลบไฟล์นี้ทิ้ง

## โครงสร้างไฟล์

```
Link/
├── app/                  โค้ดหลัก (ห้ามเข้าถึงจากเว็บ)
│   ├── auth.php          ระบบล็อกอินและสิทธิ์
│   ├── bootstrap.php     จุดเริ่มต้นของทุกหน้า
│   ├── config.php        โหลดคอนฟิก
│   ├── config.local.php  คอนฟิกจริง (สร้างตอนติดตั้ง)
│   ├── db.php            เชื่อมต่อฐานข้อมูล + สคีมา
│   ├── helpers.php       ฟังก์ชันช่วยเหลือ
│   ├── layout.php        โครง HTML ร่วม
│   └── links.php         ตรรกะของลิงก์และสถิติ
└── public/               document root
    ├── index.php         หน้าแรก
    ├── go.php            เปลี่ยนเส้นทาง /{code}
    ├── preview.php       สถิติสาธารณะ /p/{code}
    ├── install.php       ตัวติดตั้ง (ลบทิ้งหลังติดตั้ง)
    ├── admin/            หลังบ้านทั้งหมด
    └── assets/           CSS + JS
```

## ตารางในฐานข้อมูล

| ตาราง | หน้าที่ |
|---|---|
| `users` | บัญชีผู้ใช้หลังบ้าน (admin / editor) |
| `links` | ลิงก์ย่อ ปลายทาง รหัสผ่าน วันหมดอายุ ยอดคลิก |
| `clicks` | ประวัติการคลิกรายครั้ง (อุปกรณ์ เบราว์เซอร์ OS ผู้อ้างอิง IP) |
| `settings` | ค่าตั้งค่าระบบแบบ key–value |

## คำสงวน

โค้ดลิงก์ต่อไปนี้ใช้ไม่ได้เพราะชนกับเส้นทางจริงของระบบ:
`admin`, `api`, `assets`, `install`, `index`, `go`, `unlock`, `p`
